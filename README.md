# 🔎 Binance Move Detective

> The market moved. I'll find out why.

Binance Move Detective is an AI-powered market investigation agent designed to investigate unusual cryptocurrency price movements.

Instead of simply predicting whether an asset will go up or down, the agent investigates the available market evidence and explains whether a movement appears to be market-wide or asset-specific.
